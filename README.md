# HawkLabs StreamTools

Windows Twitch sound-command app by HawkLabs. Streamers choose their own sound files and commands.

## Downloads

[View releases](https://github.com/HawkLabsAi/StreamTools-Releases/releases). The first release is being prepared; a repository alone does not enable online updates.

Download the attached `HawkLabs-StreamTools-0.3.1-win-x64.zip` application package when published. GitHub's automatically generated Source code archives are not installable application packages.

## Installation and updates

- First installation: extract the entire application ZIP and open `HawkLabs.StreamTools.exe`.
- From version 0.3.0 or later: disconnect Twitch, turn chat sounds OFF, and choose Updates > Install update from file. Select a newer signed application ZIP.
- Version 0.3.1 online updates: enter `https://github.com/HawkLabsAi/StreamTools-Releases` in Updates.
- Version 0.3.0 online updates: enter `https://github.com/HawkLabsAi/StreamTools-Releases/releases/latest/download/latest.json` instead.

Online updates require a published latest release with both the application ZIP and signed `latest.json` attached. No GitHub account is needed to download public releases. Updates verify the publisher signature and package checksums and restart only after confirmation. Saved commands, sound paths and Twitch authorization stay in the local profile. Rollback is available after an update.

The app is beta software. Test updates off stream. Windows executable code signing is separate from updater signatures, so Windows may show a SmartScreen prompt.

This repository contains release downloads and public documentation. It does not contain private signing keys or streamer credentials.
